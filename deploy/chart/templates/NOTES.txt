llmgw release {{ .Release.Name }} (chart {{ .Chart.Version }}, app {{ .Chart.AppVersion }}) deployed.

Reach the gateway:
  curl http://{{ .Values.ingress.host }}/

Tail logs:
  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "llmgw.fullname" . }} -f

Trigger model validation:
  curl -X POST http://{{ .Values.ingress.host }}/v1/models/validate

Ops notes:
  - Single-replica only. SQLite + WAL on a ReadWriteOnce PVC won't tolerate concurrent writers.
  - Ollama is reached directly via the host's LAN IP (set in env.OLLAMA_BASE_URL). The cluster's
    ArgoCD installation excludes Endpoints/EndpointSlice from sync, so a Service indirection
    silently drops; the direct URL works because the host bind was rebound to 0.0.0.0:11434.
  - PVC `{{ include "llmgw.fullname" . }}-data` survives pod restarts. Wipe it to force a fresh
    credential bootstrap (re-seeds from the host `.claude` directory on next boot).
